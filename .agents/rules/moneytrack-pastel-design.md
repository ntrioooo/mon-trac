# MonTrac Pastel Lavender Design System Rules

Always adhere to the **Modern Pastel Lavender Light Design System** defined in `skills/moneytrack-pastel-design/SKILL.md`:
1. Canvas background is `#F8FAFC` with top header aurora gradient `linear-gradient(180deg, #DDD6FE 0%, #EDE9FE 45%, #F8FAFC 100%)`.
2. Cards are pure white `#FFFFFF` with `rounded-2xl` / `rounded-3xl` and soft diffused shadows (`shadow-[0_4px_20px_rgba(139,92,246,0.05)]`).
3. Semantic Color Hierarchy:
   - Violet `#7C3AED` for Brand / Wallets / Primary CTAs.
   - Mint / Emerald `#10B981` / `#4ADE80` for Income figures and positive cash flow.
   - Rose / Coral `#EF4444` / `#F87171` for Expense figures and warnings.
4. Fast Input Form Standard: All fields (Note, Date, Wallet, Category) must be displayed directly without collapsible accordions.
5. Center FAB is elevated dark navy `#0F172A` with white plus icon.
6. All text uses Plus Jakarta Sans and amounts use `tabular-nums` with high contrast `#0F172A`.
